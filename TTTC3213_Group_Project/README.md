# TTTC3213 Final Group Project
**Project Overview**

This project demonstrates a complete ETL (Extract, Transform, Load) process applied to an online shopping website.

Product data was collected using web scraping techniques, cleaned and transformed for consistency, and analyzed through simple visualizations.

**Key Features**

Extract: Scraped product information (name, price, brand, rating) using Python and BeautifulSoup

Transform: Cleaned missing values, standardized price formats, and converted data types

Load: Saved the cleaned dataset into a CSV file for further analysis

Visualization: Generated comparison charts to analyze price distribution, brand presence, and customer ratings

**Tools Used**

Python

BeautifulSoup

Pandas

Matplotlib

**Output**

Cleaned CSV dataset

Comparison charts for data analysis

ETL report documenting the process and findings
